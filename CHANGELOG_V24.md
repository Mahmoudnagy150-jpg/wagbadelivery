# Sea Gull Ultimate OWNER PRO V24

- Customer tracking link opens the public order page only.
- Customer confirmation CTA is rendered whenever the final price is ready, and confirmation sets the order to accepted.
- Owner can choose per item: Quantity / Weight / Plate.
- Weight mode is now supported for any item; fish keeps count + weight-per-fish, shrimp is weight-only, and other weight items are total weight.
- The 150g minimum applies only to fish and shrimp.
- Per-item availability toggle: Available / Currently unavailable.
- Unavailable items stay visible with a clear unavailable badge but cannot be added, and the server rejects unavailable items.
- Pricing mode and availability are stored in the shared menu.json, so they apply to all branches automatically.
- 227 menu items preserved.
