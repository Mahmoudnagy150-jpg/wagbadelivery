# Sea Gull Ultimate OWNER PRO V19 — OVER THE TOP

## أهم التحديثات
- اختيار الفرع للعميل مرة واحدة فقط قبل إتمام الطلب.
- مراجعة الوزن والكمية مع فصل واضح بين المطلوب والفعلي.
- إعادة حساب سعر الصنف من الوزن الفعلي.
- ضريبة 14% مرة واحدة فقط.
- خدمة توصيل قابلة للتعديل.
- خصم 10% بعد الضريبة والتوصيل حسب معادلة النظام.
- شيك حراري 80mm مرتب.
- إرسال الشيك والسعر النهائي للعميل عبر WhatsApp.
- رابط تتبع للعميل مع زر موافقة صريح على السعر النهائي.
- لا يستطيع موظف الفرع بدء التجهيز قبل تأكيد العميل للسعر النهائي.
- سجل تدقيق Audit Log وسجل زمني لكل طلب.
- إدارة مركزية للفروع وتقارير ومقارنة أداء الفروع.
- تعديل الأسعار والأصناف والأقسام للـOWNER فقط.
- تصفير بيانات كل فرع بشكل مستقل.
- Backup من لوحة الإدارة.

النسخة لا تحتوي على orders.sqlite جاهزًا، حتى لا تستبدل قاعدة البيانات الموجودة عند رفعها فوق موقع قائم. النظام ينشئ/يُحدّث قاعدة البيانات تلقائيًا عند التشغيل.
