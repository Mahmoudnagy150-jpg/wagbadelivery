# Sea Gull V25

- Master Menu + per-branch overrides.
- Owner can set branch availability and optional branch-specific price for every item.
- Customer selects branch before browsing; menu, prices and availability are branch-aware.
- Server validates branch availability and uses branch override prices at order creation.
- Branch menu settings are shared across all branches via one central menu with overrides.
- Existing cart/checkout/order tracking/confirmation flow retained.
